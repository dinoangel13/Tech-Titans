# 🎓 PathAI — Personalized Learning Path Recommendation

> **Make the learning path adapt to the student.**

PathAI is an **AI/ML-based personalized learning recommendation system** that recommends the next best learning path based on a student's performance, progress, behaviour, and learning patterns.

## 🚀 What It Does

PathAI analyzes:

- Quiz accuracy
- GPA
- Learning progress
- Time spent
- Number of attempts
- Engagement
- Learning style
- Education level
- Difficulty level

It generates:

**🥇 Top 3 Learning Path Recommendations + Confidence Scores + Explanations**
