🎓 PathAI — AI-Powered Personalized Learning Path Recommendation

Don't make every student follow the same path. Make the learning path adapt to the student.

PathAI is an AI/ML-based personalized learning recommendation system designed to recommend the most suitable next learning path for an individual student based on their academic performance, learning behaviour, progress, and learning context.

The system goes beyond simply predicting a learning path by providing Top-3 recommendations, confidence scores, and recommendation explanations.

🚀 Problem Statement

Every student learns differently.

Traditional learning platforms often follow a fixed learning sequence, even though students can differ significantly in:

Quiz performance
Learning speed
Number of attempts
Engagement
Learning progress
Learning style
Previous academic performance
Perceived difficulty

This can lead to two major problems:

A high-performing student may spend unnecessary time revisiting concepts they already understand.
A struggling student may be pushed toward advanced topics without sufficient mastery of prerequisites.
Our Goal

Build an intelligent recommendation system that answers:

"What is the best next learning path for this student?"

💡 Our Solution

PathAI uses machine learning to analyze a student's learning profile and recommend the most appropriate next learning paths.

The system considers multiple dimensions of student behaviour and performance rather than relying on a single metric.

Core Flow

🧠 Machine Learning Approach

The current implementation uses a Random Forest Classifier for learning-path recommendation.

The model is trained using student-level features and predicts the recommended_path target.

Model Configuration
Algorithm: Random Forest Classifier
Number of estimators: 200
Train/Test Split: 80/20
Random State: 42
Output: Recommended learning path
Ranking: Model prediction probabilities are used to obtain the Top-3 recommendations

The model also provides feature importance values that can be used to understand which input features contribute most to the prediction.

🎯 Recommendation Output

For each student, PathAI generates:

Top 3 Recommended Learning Paths
1. Recommended Path A — Confidence Score
2. Recommended Path B — Confidence Score
3. Recommended Path C — Confidence Score

Providing three alternatives prevents the system from forcing the student into a single rigid path.

The system also generates an explanation for each recommendation.

🔍 Explainable Recommendations

PathAI is designed not only to answer:

"What should I learn next?"

but also:

"Why is this recommended for me?"

The recommendation explanation considers factors such as:

Quiz performance
Learning speed
Number of attempts
Learning style
Current progress

For example, if a student's quiz performance is low, the system can prioritize foundational learning and recommend revisiting core concepts.

If the student demonstrates strong quiz performance, the system can recommend progression toward more advanced learning paths.

🌟 Key Innovations
1. Multi-Factor Personalization

Recommendations are based on multiple aspects of learning rather than only quiz marks.

Performance + Behaviour + Progress + Context

2. Top-3 Recommendation

Instead of producing a single rigid recommendation, PathAI provides three ranked alternatives with confidence scores.

3. Explainable Recommendation

The system attempts to communicate why a particular learning path is recommended based on the student's current learning profile.

4. From Prediction to Action

PathAI connects the recommendation with:

Recommendation → Study Plan → Analytics → Performance Report

This turns the ML output into something actionable for the student.
